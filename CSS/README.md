# Assignment #2 - Advanced CSS (Flexbox & Grid)

Student: Yelaman
Group: SE-2530

## Описание

Это учебное задание по предмету Web Technologies.
В проекте показано, как использовать Flexbox и CSS Grid
для создания простых и адаптивных макетов.

## Файлы

index.html - главная страница со ссылками на задания
task1.html - Task 1: хедер на Flexbox и карточки в ряд
task2.html - Task 2: макет страницы через CSS Grid
task3.html - Task 3: галерея из 9 картинок с подписью при наведении
task4.html - Part 3: Flexbox и Grid вместе

common.css - общие стили для всех страниц
task1.css, task2.css, task3.css, task4.css - стили для каждой страницы

## Как запустить

1. Скачать папку с проектом
2. Открыть файл index.html в браузере
3. Переходить по ссылкам в шапке сайта

Ничего устанавливать не нужно, всё работает сразу.
